# 分微未来智能官网 · OpenAGIX

正式域名：`https://openagix.com`。中文响应式静态官网，使用 HTML、CSS 和原生 JavaScript，无第三方运行依赖。

## 运行与检查

```sh
cd /workspace/ffi
npm start
npm run check
```

`npm start` 使用 Python 3 在 3000 端口启动静态服务。使用现有检出目录，无需新建 Git worktree；新任务需要重新启动进程。

## 已实现功能

- 3 项技术业务、8 个分享主题、5 类商业顾问，共 16 项完整详情。包含受众、服务模块、预期成果、准备条件与范围说明。
- 主题分类与关键词联合筛选、无结果提示和重置；常见问题全文搜索。
- 业务详情支持 `#service/ai-coding` 等公开标识链接、复制与浏览器后退。分享链接仅含公开业务标识，不包含咨询内容。
- 培训方案匹配根据目标、受众与人数给出参考建议；三档横向对比表可直接进入对应咨询。
- 三步咨询：选择服务、补充需求、确认与联系。按类型联动服务和方案，技术项目不混入培训人数。
- 必填、空白字符、1–100 整数人数、过去日期、邮箱格式校验；可补充城市、预算、时间和联系人。
- 仅主动保存本设备草稿，支持恢复、删除，7 天后过期。禁用存储时仍可继续填写。通用入口重新打开时保留当前内容。
- 需求单支持复制、UTF-8 文本下载、邮件客户端发送和打印 / 保存 PDF。复制失败时提供手动复制途径。
- 手机底部快捷联系、键盘关闭菜单、原生对话框焦点约束、错误提示、读屏状态、减少动态效果与无 JavaScript 联系入口。
- canonical、Open Graph、Organization 结构化数据、robots.txt 和 sitemap.xml。

## 业务内容维护

- `index.html`：页面卡片、公开报价、联系方式、FAQ、表单与对比表。
- `catalog.js`：16 项业务的详情数据。`title` 与页面卡片名称对应；`id` 用于公开链接，应保持稳定。
- `app.js`：筛选、详情、匹配、导航、咨询校验、草稿与导出。联系方式常量位于文件顶部。
- `styles.css`：视觉设计、响应式与打印样式。
- `assets/公司业务说明.md`：可下载的公司业务说明。

修改业务名称或报价时，需同步页面卡片、详情目录、需求单方案及下载文档。三档培训组合为参考包装，最终范围和报价沟通确认；转化率顾问需另行书面明确计费基数与结算方式。

## 浏览器回归测试

测试使用 Node.js 内置测试运行器与 Playwright，启动独立的临时 Python HTTP 服务，测试后关闭。Playwright 1.62.1 已固定在开发依赖和锁文件中。网站运行无需安装依赖；仅运行浏览器测试时安装开发依赖。云环境已提供 Chromium；其他机器可安装系统 Chromium 或使用 Playwright 管理的浏览器。

```sh
npm ci
# 没有系统 Chromium 时，先执行：npx playwright install chromium
npm test
# 优先使用系统 /usr/bin/chromium，否则使用 Playwright 浏览器；可覆盖：
CHROMIUM_PATH=/path/to/chromium npm test
```

覆盖全部 16 项详情与咨询上下文、分类搜索、公开链接和浏览器后退、三档匹配、方案对比、字段错误、类型切换、草稿恢复/删除/过期/禁用存储、剪贴板降级、文本内容和邮件编码、打印、手机导航、七档屏宽及无 JavaScript 回退。

## 打包与部署

```sh
npm run build
# 或指定部署包位置：
python3 scripts/package.py /workspace/openagix-website.zip
```

部署包仅含公开静态资源与说明，不含测试、开发依赖或本设备草稿。构建默认输出 `dist/openagix-website.zip`。

将部署包解压到静态网站托管服务。发布目录为解压根目录，无构建或运行依赖；务必包含新增的 `catalog.js`。绑定 `openagix.com` 后，按照托管服务提供的 DNS 记录在 Dynadot 配置并启用 HTTPS。

当前完成本地运行验证，尚未发布到互联网，也未修改域名解析。生成部署包、保存环境配置与正式网站上线是不同操作。
